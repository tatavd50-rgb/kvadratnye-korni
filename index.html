01

Свойства арифметического квадратного корня

Арифметический квадратный корень из числа a обозначают √a: знак √ называют знаком арифметического квадратного корня, а выражение, стоящее под ним, — подкоренным выражением. По определению √a = b, если выполняются два условия: b ≥ 0 и b² = a. При a < 0 выражение √a не имеет смысла.

Арифметическим квадратным корнем из неотрицательного числа a называют такое неотрицательное число b, что b² = a. Из этого определения следуют пять базовых свойств.

√(a·b) = √a · √b

при a ≥ 0, b ≥ 0

Корень из произведения равен произведению корней.

√(a⁄b) = √a ⁄ √b

при a ≥ 0, b > 0

Корень из дроби, числитель которой неотрицателен, а знаменатель положителен, равен корню из числителя, делённому на корень из знаменателя.

√(a²) = |a|,  (√a)² = a

a — любое; во втором случае a ≥ 0

Корень «снимает» квадрат по модулю; возведение корня в квадрат возвращает подкоренное число.

√a · √b = √(a·b)

при a ≥ 0, b ≥ 0

Произведение корней равно корню из произведения подкоренных чисел.

√a ⁄ √b = √(a⁄b)

при a ≥ 0, b > 0

Частное корней равно корню из частного подкоренных чисел.

Разобранные примеры

  1. √(4·9)= √4 · √9 = 2 · 3= 6
  2. √(81⁄9)= √81 ⁄ √9 = 9 ⁄ 3= 3
  3. √((−7)²)= |−7|= 7

04

Вынесение корня

Если подкоренное число раскладывается на множители так, что один из них — точный квадрат, его можно «вынести» из-под корня:

√(a²·b) = |a| · √b

Ищем в числе под корнем наибольший квадратный множитель.

Разобранные примеры

  1. √72= √(36·2) = √36·√2= 6√2
  2. √48= √(16·3) = √16·√3= 4√3

Задачи для отработки

Впишите коэффициент и число под корнем: например, для √8 = 2·√2 — коэффициент 2, под корнем 2.

05

Внесение корня

Действие, обратное вынесению: множитель перед корнем возводится в квадрат и заносится под корень.

a · √b = √(a²·b)

при a ≥ 0, b ≥ 0

Множитель a «превращается» в a² внутри корня.

Разобранные примеры

  1. 3√5= √(3²·5) = √(9·5)= √45
  2. 4√2= √(4²·2) = √(16·2)= √32

Задачи для отработки

Впишите число, которое окажется под корнем.

Преобразование выражений, содержащих квадратные корни

Три приёма встречаются чаще всего: приведение подобных корней, освобождение от иррациональности в знаменателе и применение формулы разности квадратов.

m√a + n√a = (m+n)√a

Подобные корни складываются, как одночлены.

1⁄√a = √a⁄a

при a > 0

Умножаем числитель и знаменатель на √a.

(√a−√b)(√a+√b) = a−b

Разность квадратов убирает оба корня.

Разобранные примеры

  1. (√3−1)(√3+1)= (√3)² − 1² = 3 − 1= 2
  2. 6⁄√6= 6√6⁄6= √6
